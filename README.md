# Git_learnner

## 📋 Learning Progress Checklist

### Git Basics
- [ ] Understand what Git is and why it's used
- [ ] Install Git and configure username/email
- [ ] Initialize a repository (`git init`)
- [ ] Clone a repository (`git clone`)

### Working with Files
- [ ] Check repository status (`git status`)
- [ ] Stage files for commit (`git add`)
- [ ] Commit changes (`git commit`)
- [ ] View commit history (`git log`)

### Branching & Merging
- [ ] Create a new branch (`git branch`)
- [ ] Switch between branches (`git checkout` / `git switch`)
- [ ] Merge branches (`git merge`)
- [ ] Resolve merge conflicts

### Remote Repositories
- [ ] Add a remote (`git remote add`)
- [ ] Push changes to remote (`git push`)
- [ ] Pull changes from remote (`git pull`)
- [ ] Fetch changes (`git fetch`)

### Advanced Topics
- [ ] Stash changes (`git stash`)
- [ ] Rebase branches (`git rebase`)
- [ ] Use `.gitignore` to exclude files
- [ ] Tag releases (`git tag`)
- [ ] Undo changes (`git revert` / `git reset`)
